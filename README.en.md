# 🎯 Number Guessing Game

A simple number guessing game written in **Bash**.

The program randomly chooses a number between **0 and 9**, and the player tries to guess it. After each incorrect guess, the program gives a hint indicating whether the chosen number is higher or lower.

## 📁 Versions

This project contains two language versions:

* 🇦🇿 Azerbaijani — `az/game.sh`
* 🇬🇧 English — `en/game.sh`

## 🛠️ Technologies

* Bash
* Linux Terminal

## 🎮 How It Works

1. The program randomly selects a number from 0 to 9.
2. The player enters a guess.
3. The program checks whether the input is a valid number.
4. If the guess is too high or too low, the program gives a hint.
5. The game continues until the correct number is guessed.

## ▶️ How to Run

### Azerbaijani Version

```bash
chmod +x az/game.sh
./az/game.sh
```

### English Version

```bash
chmod +x en/game.sh
./en/game.sh
``
