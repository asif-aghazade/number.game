## Rəqəm Tapma Oyunu

*Bash* proqramlaşdırma dili ilə hazırlanmış sadə rəqəm tapma oyunu.

Proqram **0-dan 9-a qədər** təsadüfi bir rəqəm seçir və oyunçu həmin rəqəmi tapmağa çalışır. Hər səhv cavabdan sonra proqram seçilmiş rəqəmin daxil edilən rəqəmdən böyük və ya kiçik olduğunu bildirir.


## Versiyalar
Layihədə iki dil versiyası mövcuddur:

* 🇦🇿 Azərbaycan dili — `oyun.sh`
* EN İngilis dili — `game.sh`


## Oyunun işləmə prinsipi
1. Proqram 0-9 arasında təsadüfi rəqəm seçir.
2. Oyunçudan rəqəm daxil etməsi istənilir.
3. Proqram daxil edilən məlumatın düzgün rəqəm olub-olmadığını yoxlayır.
4. Daxil edilən rəqəm böyük və ya kiçik olduqda proqram istiqamət verir.
5. Düzgün rəqəm tapılana qədər oyun davam edir.



## Oyunu işə salmaq

# Azərbaycan dili
/bin/bash
chmod +x oyun.sh
./oyun.sh

# İngilis dili
/bin/bash
chmod +x game.sh
./game.sh
